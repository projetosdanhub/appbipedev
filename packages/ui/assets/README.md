# Marca

`bipesend-logo.webp` é cópia sem alteração do ativo já presente nos apps. Apesar do nome legado “vertical”, a arte disponível é horizontal (1080 × 328). Não foi encontrada uma segunda composição vertical oficial nesta revisão.

BrandLogo mantém proporção, alt=BipeSend e superfície branca para legibilidade em dark. Não distorcer, cortar, recolorir ou inventar uma nova assinatura. A variante vertical e a versão reversa ficam pendentes de inclusão do arquivo oficial.

O comando `pnpm brand:sync` copia o ativo canônico para os caminhos públicos compatíveis dos apps. Alteração da marca deve ocorrer primeiro aqui, preservando direitos e revisão visual.
