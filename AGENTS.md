# Regras do Sistema Bipesend

## Tipografia (Design System)
- **Títulos (Headings):** Utilize a fonte **Inter**.
- **Textos (Body/Parágrafos/Componentes):** Utilize a fonte **Poppins**.

## Cores (Design System)
- Azul principal: #007BFF
- Lilás / roxo secundário: #6366F1
- Preto / azul muito escuro (Textos): #0F172A
- Branco / fundo claro (Surface): #F8FAFC
- Degradê principal (ex: Botões primários): bg-gradient-to-r from-[#007BFF] to-[#6366F1]
