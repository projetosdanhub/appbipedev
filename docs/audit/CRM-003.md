# CRM-003 Pipelines (Kanban)

## Implementação Realizada
1. **Infraestrutura**: Adicionados os métodos `deletePipeline` e `deleteStage` em `PipelineRepository`.
2. **Segurança de Dados**: 
   - Ao deletar um pipeline, verifica se existem negócios (deals) associados. Retorna erro `CANNOT_DELETE_PIPELINE_WITH_DEALS` se houver.
   - Ao deletar um estágio, verifica se existem negócios associados ao estágio. Retorna erro `CANNOT_DELETE_STAGE_WITH_DEALS` se houver.
3. **Serviços**: Adicionadas as rotas e autorizações no `PipelineService` garantindo a permissão `crm.pipelines.manage`.
4. **Testes Unitários**: Criado arquivo `pipeline.service.test.ts` cobrindo sucesso na criação, falha por falta de permissão e bloqueio de exclusão em caso de negócios existentes. Foram adicionados bypasses de RLS adequados para simular a criação dos dados no teste.

## Testes
A suíte `PipelineService` possui 3 testes, todos executando com sucesso:
- `should create a pipeline successfully`
- `should fail to create pipeline if permission is missing`
- `should block deletion of stage if deals exist`
