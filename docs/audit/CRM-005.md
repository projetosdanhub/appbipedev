# CRM-005 Conversas e Mensagens Internas

## Implementação Verificada

### Backend
1. **Contratos** (`packages/contracts/src/inbox.ts`):
   - `conversationSchema`, `messageSchema`, `conversationReadStateSchema`, `conversationStatusHistorySchema`
   - Enums: `conversationSourceSchema` (internal_crm, whatsapp, instagram, messenger, email), `messageKindSchema` (internal_note, customer_message, system_event), `messageStateSchema` (sending, sent, delivered, read, failed, saved)
   - Create/update schemas para conversation, addInternalNote, sendOutboundMessage

2. **Domain** (`06-inbox/domain/`):
   - `ConversationEntity`: Factory method `create()` para nova conversa
   - `MessageEntity`: Factory methods `createInternalNote()` e `createOutboundMessage()`

3. **Infrastructure** (`06-inbox/infrastructure/`):
   - `ConversationRepository`: CRUD completo, `updateStatus` com histórico de transição, `updateReadState` com upsert idempotente, `update` com assignment history e outbox event
   - `MessageRepository`: Criação de notas internas e mensagens outbound, listagem paginada com `afterSequence`/`beforeSequence`
   - `messages-queue.ts`: Integração com BullMQ para envio assíncrono de mensagens outbound

4. **Application** (`InboxService`):
   - `createConversation`, `getConversation`, `getConversationsByContact`, `getAllConversations`
   - `addInternalNote`: Cria nota interna SEM acionar provedores/webhooks
   - `sendOutboundMessage`: Cria mensagem e enfileira no BullMQ para envio
   - `updateConversationStatus` com histórico
   - `updateReadState`
   - `assign`, `claim`, `release` com optimistic locking

5. **Presentation** (`inbox.controller.ts`):
   - 393 linhas com endpoints REST completos
   - CRUD conversations, messages, status, read state, assignment, claim, release

### Frontend
1. **InboxClient** (`inbox/inbox-client.tsx`): 41KB — painel completo de inbox com lista de conversas, painel de mensagens, notas internas e envio
2. **InboxPage** (`inbox/page.tsx`): Server component buscando conversas e passando para o client
